# 🎮 Guess the Number Game (Single Player)

**Guess the Number Game** is a simple Python console game where the computer randomly chooses a secret number and the player tries to guess it within a limited number of attempts.

This project is beginner-friendly and focuses on practicing core Python concepts like input handling, loops, and conditional logic.

---

## 🕹️ Game Rules

- The computer randomly selects a number between **1 and 10**.
- You have **3 attempts** to guess the correct number.
- After each guess, the game tells you:
  - 📉 If your guess is too low
  - 📈 If your guess is too high
- If you enter something that is **not a number**, the game will prompt you again.
- If your guess is **outside the allowed range**, you’ll be warned.
- 🎉 Guess the number correctly and you win!
- ❌ If you use all attempts, the game ends and reveals the secret number.

---

## ▶️ How to Run the Game

1. Make sure you have **Python 3** installed.
2. Save the file as `guess_the_number_game.py`.
3. Open a terminal in the same directory.
4. Run the game using:

```bash
python guess_the_number_game.py
```
